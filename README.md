# Consumer-Shopping-Behaviour-and-Buying-Survey
A SQL Server and Power BI project analysing consumer shopping behaviour through data cleaning, demographic analysis, shopping preferences and purchasing patterns. It includes 40 beginner-to-intermediate SQL questions using aggregate functions, CASE statements, CTEs, grouping and conditional filtering. The project also features an interactive Power BI dashboard that presents key insights through KPI cards, filters and visualisations covering shopping preferences, spending categories, BNPL usage and impulse-purchasing behaviour.
